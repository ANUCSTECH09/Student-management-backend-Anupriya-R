# Student Management Backend API

## Project Overview
A Student Management REST API built using Java, Spring Boot, and MySQL.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- Postman

## Features
- Create student records
- View student records
- Update student details
- Delete student records
- Search by name and register number
- Filter by department, year, and semester
- Input validation
- Error handling
